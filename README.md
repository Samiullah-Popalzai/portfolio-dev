# Portfolio Website (Laravel)

A simple four-page portfolio website built with Laravel to practice the basics:
routes, controllers, Blade layouts, and passing data to views.

## Pages

- Home
- About
- Projects
- Contact

## Built With

- PHP
- Laravel
- Blade
- CSS

## Requirements

- PHP 8.2 or higher
- Composer
- Node.js and npm (if using Vite)

## Installation

1. Clone the repository:

    git clone https://github.com/yourname/portfolio-dev.git
    cd portfolio-dev

2. Install dependencies:

    composer install
    npm install

3. Set up the environment:

    cp .env.example .env
    php artisan key:generate

4. Run the app:

    php artisan serve
    npm run dev

5. Open http://127.0.0.1:8000

## What I Learned

- Routing and named routes
- Controllers and Blade layouts
- Passing data to views and looping with @foreach
